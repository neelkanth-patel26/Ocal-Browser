Network Troubleshooting Checklist
AUTO-POLLING: 10s
1

Check Physical Connection

Verify that your Wi-Fi is toggled on, or that your Ethernet cable is firmly seated into your computer and router.

2

Reboot Modem or Flush DNS

Restart your router, or open Windows Terminal and run ipconfig /flushdns to clear stale records.

3

Check Firewall & Proxies

Make sure any third-party VPN, antivirus firewall, or HTTP proxy is not blocking outbound web requests.

4

Windows Network Troubleshooter

Right-click the network icon in the Windows taskbar and choose Diagnose network problems.
